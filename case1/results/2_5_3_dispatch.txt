VALUES 8-12
--------------------------------------------------------------------------
  The compiled bounds check is `mov x30,#0xd; cmp w25,w30; b.hs default`,
  so 0..12 index the table and 13+ skip it. Table entries 8..12 all hold
  the default block, because CIL switch targets 8..12 are all 81550, which is
  the shared tail. So StartTcpCmd, StopTcpCmd, StartBroadCast,
  StopBroadCast and SelfDestroy are declared in the enum and are not
  handled here: they fall to `OnCompleted(_task, respFile)` and produce
  no action.  [static, from the switch instruction]

  How far that goes: `get_TaskName` has two consumers in the
  assembly. This lambda is one; the other is `UpdateServer` itself,
  which uses it to build a progress string (IL 0x011C -> String.Concat
  -> OnProgress), not to dispatch. So there is no second dispatcher on
  TaskName. That covers the TaskName enum and this routine only. The
  build may well have another command surface elsewhere.  [static]
